# Algorithm Roadmap

> A structured roadmap for mastering Algorithms, Data Structures, and Competitive Programming.

---

## About

Algorithm Roadmap is an open-source learning repository designed to help programmers build a strong foundation in algorithms and competitive programming.

Instead of being a collection of random notes or solutions, this repository follows a carefully designed learning path where each topic builds upon previously learned concepts.

The goal is to create a resource that is useful for both beginners and experienced programmers who want a well-organized reference.

---

## Goals

This repository aims to:

* Build a solid understanding of algorithms and data structures.
* Improve competitive programming problem-solving skills.
* Provide clean and well-documented reference implementations.
* Organize knowledge based on prerequisites rather than difficulty.
* Serve as a long-term reference for revision and learning.

---

## Features

* 📚 Structured learning roadmap
* 🧠 Intuition-first explanations
* 💻 Clean C++ reference implementations
* 📝 Detailed algorithm documentation
* 🎯 Carefully selected Codeforces practice problems
* 🔗 Cross-linked algorithms and problems
* 🌱 Beginner-friendly progression

---

## Getting Started

If you're new to this repository, follow this order:

1. Read the Learning Roadmap.
2. Study each algorithm in order.
3. Review the reference implementation.
4. Solve the recommended practice problems.
5. Continue to the next topic.

## Documentation Structure

Each algorithm has its own directory containing:

* `README.md`
* `implementation.cpp`

The documentation includes:

* Overview
* Intuition
* Prerequisites
* When to Use
* When NOT to Use
* Pattern Recognition
* Complexity Analysis
* Implementation Walkthrough
* Common Mistakes
* Practice Problems
* Related Algorithms
* Learning Path

---

## Practice Problems

Problems are stored separately from algorithms.

Only Codeforces problems with significant educational value are included.

Each problem contains:

* Problem Information
* Solution Idea
* Complexity Analysis
* Related Algorithms
* Reference Solution
